# Dynauzôr
Pas de bras pas de projet, nommé "Dynozor" ou "Tour de Pise", est un projet où l'on met le code et les modèles 3d d'un bras en cours de développement. Si le bras, les pieces ou outils vous intéressent, vous pouvez les trouver dans les fichiers ci-dessous.

**ATTENTION** il faut aussi suivre le tutoriel du code pour faire marcher le bras. N'hésitez pas à chercher sur google ou chatgpt si vous ne comprenez pas quelque chose.

Vous pouver trouver les tutoriels pour l'assembler;

Vous pouver trouver le code et le tutoriel du code and "Le code".
